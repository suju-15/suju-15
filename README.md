### » Featured projects

- **Retro Mini — Handheld Game Console**
  A pocket 8-bit console built on an ESP32-C3 SuperMini with a 0.96" SSD1306 OLED display. Five playable games — Snake, Pong, Tetris, Space Dodge and Flappy Bird — with a D-pad, haptic feedback and a single-cell LiPo battery.
  → [retro_mini_v1.0](https://github.com/suju-15/retro_mini_v1.0)

- **MPU6050 I2C Driver (ESP-IDF)**
  A clean, reusable ESP-IDF component for the MPU6050 accelerometer and gyroscope, built on the modern `i2c_master` driver with efficient burst reads.
  → [mpu6050_i2c_driver](https://github.com/suju-15/mpu6050_i2c_driver)

- **ESP32 Weather Monitor**
  An ESP32-C3 weather station that pulls live conditions from OpenWeatherMap and shows indoor and outdoor temperature and humidity on an OLED, using a DHT22 sensor with a button-driven multi-screen UI.
  → [Arduino_projects](https://github.com/suju-15/Arduino_projects)
